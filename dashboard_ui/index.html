First-run Windows 11 setup

From PowerShell opened in the repository root:

py -3.12 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements-dev.txt
python dashboard_server.py --mock

Open http://127.0.0.1:8787. Stop mock mode with Ctrl+C, then run python dashboard_server.py for read-only host discovery.
